#### Pour ajouter des cartes depuis votre barre de signets

À la manière des signets partagés, vous pouvez ajouter des cartes à partir de contenus web avec un simple bouton à ajouter à votre navigateur.

- déplacer ce bouton dans votre barre de signets : <a class="yw-btn yw-btn--primary" href="javascript:var wleft = (screen.width-700)/2; var wtop=(screen.height-530)/2; window.open('{bookmarkletUrl}'+encodeURIComponent(document.title)+'&bf_ressources='+encodeURIComponent(location.href)+'&bf_chapeau='+encodeURIComponent(document.getSelection()), 'bf_bookmarklet', 'height=530,width=700,left='+wleft+',top='+wtop+',toolbar=no,location=no,directories=no,status=no,scrollbars=yes,resizable=yes,menubar=no');void 0;">+qrcard</a>
- puis aller sur la page que vous voulez transformer en carte
- sélectionner le texte dans la page qui servira de description courte
- puis cliquer sur votre signet **+qrcard** pour ajouter des QR cartes avec un simple clic depuis votre navigateur.
