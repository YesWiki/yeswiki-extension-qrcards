# yeswiki-extension-qrcards

 - [English](#english)
 - [Français](#français)

## English

[YesWiki](https://yeswiki.net/) extension. Creates printable cards with an attached QR code to extend the experience online.

### Authors

 - all contributors indicated on this page : <https://github.com/YesWiki/yeswiki-extension-qrcards/graphs/contributors>

### Install

On your wiki's `/admin/updates` screen, install the `qrcards` extension: installing it switches it on. From a shell: `./yeswicli extension:enable qrcards`, then `./yeswicli migrate` to create the cards' forms and pages. Version `5.x` is for YesWiki Ectoplasme, `4.x` for Doryphore.

### Usage

Usage help is on your wiki's `/doc` page once the extension is on, and here: https://github.com/YesWiki/yeswiki-extension-qrcards/blob/ectoplasme/docs/en/README.md
